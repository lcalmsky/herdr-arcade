# herdr-arcade brief

## 세계

- 80년대 동네 오락실 내부, 정면에서 살짝 내려다본 시점(약 15도), 도트 픽셀아트
- 기능은 `herdr-chiikawa-cards` 와 같음: 세션 카드 줄(Needs you / Working / Done), 장면 패널, 레일, 탭, 계정 팝업, 편집기 패널, 키 범례, 단축키 전부 동일
- 기존 herdr 레포와 겹치지 않음: 관제탑·마을·가챠·해변·궁궐 컨셉은 쓰지 않음

```
┌ 레일: 게임 목록판 ┬ 탭 = 토큰 버튼 · 검색 = 이니셜 입력 · ? = HOW TO PLAY ┐
│ 저장소 = 게임 타이틀 │ CONTINUE? │ NOW PLAYING │ GAME OVER │ 장면: 오락실 │
│ 공간 = 플레이어 줄   │ 마키 카드  │ 마키 카드    │ 마키 카드  │ 오락기 줄    │
│ 앞머리 = 픽셀 얼굴   │                                     │ 캐릭터, 의자 │
│ 하단: 동전 교환기    ├──────────────── 터미널 (CRT) ──────────────────────┤
│ = 계정 사용량        │                                                    │
```

## 세션의 표현 단위

- 세션 하나 = 오락기 한 대 + 픽셀 캐릭터 한 명
- 세션 카드 = 그 오락기의 마키(상단 간판) 모양 카드. 화면 창에 상태 문구

## 상태별 행동

| 상태 | 캐릭터 | 오락기 화면 / 주변 |
|---|---|---|
| Working | 자기 기계 앞에서 등을 보이고 조이스틱을 흔들며 플레이 | 화면이 번쩍이며 게임 진행 |
| Needs you | 뒤돌아 화면 쪽(사용자)을 보고 통로 앞으로 한 걸음, 머리 위 `!` | 화면에 `CONTINUE? 9…8…` 카운트다운, 말풍선에 마지막 질문 한 줄 |
| Stalled | 플레이 자세로 굳음, 머리 위 `…` | 화면 `PAUSE`, 깜박임 멈춤 |
| Done (안 읽음) | 두 팔 들고 환호 | 화면 `HIGH SCORE!` 와 반짝이 |
| Done (읽음) / idle | 뒤쪽 벤치에서 졸기, `zzz` | 화면은 어둑한 데모 화면 |
| 새 세션 | 입구 문으로 들어와 빈 기계로 걸어감 | |
| 기계보다 세션이 많음 | 남은 캐릭터는 플레이어 뒤에서 구경 | |

## 캐릭터 출처

- 창작 컨셉이므로 새로 생성. 기존 게임 캐릭터(어떤 IP도)를 닮게 만들지 않음
- 9명의 서로 다른 픽셀 캐릭터, 포즈: 뒷모습 플레이, 정면, 환호, 졸기, 걷기

## 분위기와 화풍

- 어두운 실내, 네온 사인과 오락기 화면 빛이 주 광원
- 짙은 남보라 바탕, 마젠타·시안·노랑 네온, 우주 무늬 카펫
- 도트 픽셀아트, 굵은 픽셀 외곽선, 제한된 팔레트, 디더링

## 생성 방식, 범위

- 생성: 사용자의 로그인된 ChatGPT 탭을 aside 로 조작해 내가 생성
- 순서: 전체 화면 시안(= 화풍 기준) → 사용자 확인 → 배경 → 오락기 시트 → 캐릭터 시트 → 소품·효과
- 범위: 처음부터 끝까지 (레포 생성 → 에셋 → mod 구현 → 스크린샷 검수)
